# StudyFlow

StudyFlow es un proyecto académico de desarrollo de aplicaciones móviles realizado con NativeScript y Angular para la asignatura Programación de Aplicaciones Móviles.

## Tecnologías

- NativeScript
- Angular
- TypeScript
- SCSS y CSS

## Funcionalidades implementadas

- Visualización de tareas de ejemplo.
- Cambio de estado de las tareas.
- Componentes reutilizables.
- Navegación mediante menú lateral.

## Estado del proyecto

El proyecto se encuentra en desarrollo y corresponde al alcance implementado para la actividad académica actual.

## Ejecución

Instalar las dependencias:

```bash
npm install
```

Ejecutar en un dispositivo o emulador Android configurado:

```bash
ns run android
```
